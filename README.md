# حاسبة تكلفة الوجبات

برنامج بسيط (ملف واحد `index.html`) لحساب تكلفة كل وجبة بالدينار الأردني:
المواد + الزيت + المصاريف التشغيلية (نسبة من سعر البيع) + نقص طبخ الدجاج، مع سعر البيع والربح وأزرار الطباعة.

## التشغيل على GitHub Pages
1. أنشئ مستودع جديد على GitHub وارفع الملفين `index.html` و `README.md`.
2. من Settings ثم Pages اختر: Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
3. بعد دقيقة بيصير الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## ملاحظات
- التعديلات (الأسعار، الكميات، سعر البيع، الإعدادات) بتنحفظ تلقائياً داخل متصفح الجهاز اللي بتشتغل عليه، ومش بتنتقل لجهاز ثاني.
- لو رفعت نسخة `index.html` جديدة، المتصفح بيضل يعرض آخر تعديلاتك المحفوظة عنده. لمسح المحفوظ امسح بيانات الموقع من إعدادات المتصفح.
- الطباعة بتفتح نافذة جديدة فيها التقرير، اسمح بالنوافذ المنبثقة إذا انحجبت.
- الصفحة بتستخدم خط IBM Plex Sans Arabic من Google Fonts، وإذا ما انحمّل بتستخدم خط النظام.
